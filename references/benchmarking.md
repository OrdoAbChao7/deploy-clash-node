# 可复现性能与稳定性

记录日期/时区、地点/ISP、服务端资源/版本、客户端版本/模式、节点与组、目标/对象大小、并发、超时、预算和停止阈值。普通报告用别名。预算包含双向流量、重试、协议开销，额度未知不假设免费。

## 顺序与网络

逐节点延迟 → 下载/上传 → UDP/DNS → GitHub/ChatGPT → 故障转移 → 稳定性；串行执行，每步有停止条件，大流量不与稳定性并行。至少在目标 Wi-Fi 与蜂窝分别记录订阅更新、手动选点和真实出口；不同网络、客户端、内核的结果不互换。报告写明网络标签、客户端/内核版本、代理模式和 DNS 路径。

逐节点固定选择，不让 AUTO 掩盖差异；大流量串行，每协议至少三次，保留样本和中位数。上传使用 20–50 MB 无敏感文件，下载固定大小资源。区分 DNS/连接/握手/TTFB/总时长与有效传输速度，明确 MB/s 与 Mbit/s。延迟用足够样本给 P50/P95 和样本数，三个样本不证明长期尾延迟。

| 必测 | 证据 |
|---|---|
| 延迟/成功率 | P50/P95、成功数/总数、每次时长和失败分类 |
| 下载/上传 | 字节/传输时间、三次中位数、重试/端点 |
| UDP | SOCKS UDP ASSOCIATE 或真实 QUIC/UDP 往返，TCP DNS 不能替代 |
| DNS | 冷热缓存、解析路径/答案、时延、失败率 |
| GitHub | 实际 clone、固定 Release 下载和大小/hash，首页 200 不替代 |
| ChatGPT | 页面内容/标题，必要时授权的浏览器登录和实际交互；首页 200 不证明 OAuth/API |
| 资源 | CPU/RAM/Swap/cgroup 峰值/OOM/接口字节与采样时间 |
| 故障转移 | 授权隔离注入或生产窗口、实际节点/切换时长/恢复/会话影响 |

稳定性不与大流量并行，每节点分别给时长和成功率。单节点结果不能推广全节点。区分 429、无效域名、WAF 403、认证 401、端点限速和代理故障；HTTP错误不算应用成功。超预算或生产受影响立即停止，不自动增加测试量。

报告未测项、端点限制、失败分母、原始样本位置；恢复生产组选择并清理本任务 PID/临时配置。性能排名仅适用于当次环境。
