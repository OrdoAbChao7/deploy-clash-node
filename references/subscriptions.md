# 统一 HTTPS 订阅

将所有实际部署且验证的节点合成一个 Mihomo 订阅，不能生成未部署的可用节点。用密码学随机 Token（例如 32 随机字节）创建新精确路径，保留旧订阅及凭据直到获准迁移/撤销。URL 是凭据，只写受保护文件；报告给文件位置和导入步骤，不回显 URL。

Nginx 使用可信 HTTPS、精确 location、其他路径 404、禁止目录列表、private/no-store。保护 access/error 以及上游/CDN日志中的敏感路径；禁用订阅 access log 或使用不含 URI/参数的格式。请求后核对日志增量，不能仅看配置存在。nginx -t 原始错误也可能含路径，受保护保存。

服务器外正常验证证书并拉取；URL 经 stdin 或受保护 curl 配置传递，不进入 argv。比较原始 hash 或节点/组/规则语义、全部节点及旧 URL 兼容。回环测试不证明公网可达。

还需经生产 Script.js/merge/扩展转换后校验最终配置和实际内核，测试客户端更新。解释本地导入副本与远程更新关系。不要编辑生成的 clash-verge.yaml。

限时访客能力保留：独立访客认证凭据和订阅 Token、明确时区/到期、定时撤销凭据并使 URL 返回 410。只让 URL 失效不能撤销已下载配置；到期头仅用于显示，不是鉴权/配额。验证新连接拒绝、现有连接实际行为、owner 凭据、时钟/timer 精度和失败恢复。重启共享核心会影响其他连接，不能承诺无中断。并发修改需锁、备份、配置校验及失败恢复，敏感结果只写受保护文件。

源码原 expiring-subscription 扩展保持原样，未经专门修订和隔离复测不可自动执行，不作为本次安装包的成熟脚本；已知问题含敏感日志/argv、固定日期及输入处理。上述等价工程工作流继续支持访客发放/撤销目标。
